# uv constraints for the mcpo container.
#
# mcpo 0.0.20 imports `streamablehttp_client` from mcp.client.streamable_http —
# a 1.x SDK API that was renamed to `streamable_http_client` in mcp SDK 2.0.
# mcpo's dependency is declared as `mcp>=1.17.0` with no upper bound, so uv
# happily resolves mcp 2.x and mcpo crashes on startup with:
#   ImportError: cannot import name 'streamablehttp_client' ...
#
# The official MCP Python SDK guidance is to keep a <2 upper bound until
# dependents migrate (https://github.com/modelcontextprotocol/python-sdk).
# mcpo is unmaintained at 0.0.20 (no fixed release), so pin it here.
#
# reach-mcp itself is unaffected (it uses FastMCP, which pins its own mcp).

mcp<2
